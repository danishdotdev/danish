# Danish Khan — Portfolio

Source code for [danish.sh](https://danish.sh).

## Make a change

1. Create a branch from `main`.
2. Update the portfolio content in `src/app/page.tsx` or styles in `src/app/globals.css`.
3. Run `npm install` once, then `npm run dev` to preview locally.
4. Open a pull request, or merge a reviewed change into `main`.

Vercel is connected to this repository. Every push to `main` automatically deploys the production site; pull requests receive a preview deployment.

## Project structure

- `src/app/page.tsx` — portfolio content and components
- `src/app/globals.css` — visual design, themes, and responsive behaviour
- `public/portfolio/` — portfolio images and logos
