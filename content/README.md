# Danish Khan editorial system

`editorial-plan.json` is the source of truth for the 100-post series. A post cannot be published until it has:

1. A distinct primary intent and no overlap with an already-published post.
2. At least one reviewed, authoritative source that directly supports every factual claim.
3. An honest distinction between Danish's first-hand experience and externally sourced facts.
4. A descriptive title, meta description, canonical URL, Article schema, and relevant internal links.
5. A unique black-and-white, fine-pixel editorial cover—not a stock or cartoon image.
6. A link check for every external reference before publication.

The “source” in the plan is a required verification starting point, not text to copy. Posts should link to it only where it supports a claim.
